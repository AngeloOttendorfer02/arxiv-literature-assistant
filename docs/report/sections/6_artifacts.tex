\section{Artifacts and References}
\label{sec:artifacts}

\paragraph{Repository.}
Code, tests and setup instructions are provided in this repository.
The README covers setup with \texttt{uv}, a mock mode without database or model, the Docker start (\texttt{compose.yaml} with \texttt{db}, \texttt{api} and \texttt{ui}; Dockerfiles in \texttt{docker/}) and running with real components.
The database is pre-seeded from a dump: \texttt{scripts/restore\_database.py} restores it into a fresh ParadeDB database and creates roles and indexes from the repository's SQL files.
Since LitSearch's licensing status is unclear, the dump is shared only within the team.
Alternatively, the database can be built from scratch: \texttt{scripts/download\_data.py} downloads the fixed LitSearch version listed in Table~\ref{tab:provenance}.
The README then explains how to clean the data, select papers for chunking, load the database, generate embeddings and create the search indexes.

\paragraph{Provenance.}
LitSearch~\cite{ajith2024litsearch} is obtained from Hugging Face\footnote{\url{https://huggingface.co/datasets/princeton-nlp/LitSearch}} and is not redistributed.
Table~\ref{tab:provenance} lists Hugging Face identifiers and recorded revisions.
Dataset and embedding revisions are pinned in the code; NLI and Prompt Guard are loaded without a pinned revision, so the table records their evaluated and locally cached snapshots, respectively.
Library versions are locked in \texttt{uv.lock}; the main ones are torch 2.14.1, transformers 5.20.2, sentence-transformers 6.2.0, FastAPI 0.143.3, Streamlit 1.66.0, psycopg 3.3.6, Presidio Analyzer 2.2.364 and spaCy 3.8.16.
