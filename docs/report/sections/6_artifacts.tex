\section{Artifacts and References}
\label{sec:artifacts}

\paragraph{Repository.}
Code, tests and setup instructions are provided in this repository.
The README covers setup with \texttt{uv}, a mock mode, docker compose (\texttt{db}, \texttt{api}, \texttt{ui}; Dockerfiles in \texttt{docker/}) and the inference server on Modal (\texttt{deploy/modal/}).
The database is pre-seeded from a dump: \texttt{scripts/restore\_database.py} restores it into a fresh ParadeDB database and creates roles and indexes; since LitSearch's licensing status is unclear, the dump is shared only within the team.
Alternatively, \texttt{scripts/download\_data.py} downloads the pinned LitSearch revision and the README describes the build from scratch.

\paragraph{Provenance.}
LitSearch is obtained from \url{https://huggingface.co/datasets/princeton-nlp/LitSearch} and not redistributed.
Hugging Face models: \nolinkurl{ibm-granite/granite-embedding-english-r2}~\cite{hf_granite}, \nolinkurl{dleemiller/ModernCE-large-nli}~\cite{hf_modernce} and \nolinkurl{meta-llama/Llama-Prompt-Guard-2-86M}~\cite{hf_promptguard}; the LLM is the Ollama tag \texttt{qwen3.8:27b-q4\_K\_M}~\cite{ollama_qwen38}.
Libraries are locked in \texttt{uv.lock}; Table~\ref{tab:provenance} lists revisions, versions and the source and hardware of every figure.
