## Notes

- The answer is replayed from the retrieved sources and arrives without delay, so `generate` is the time of the sentence checks; a language model adds its own time on top (see the benchmark). The plan is fixed (S1), so `plan` is not the planner.
- The questions are the harmless questions of `eval/guardrails`, all run as S1.
- Figures depend on the machine and on the number of retrieved sources and sentences. Models without a remote setting run on the CPU in the API process, also when the language model runs on Modal. A remote NLI or evidence guard adds the network round trip to Modal.
